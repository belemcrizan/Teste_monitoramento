# Glossário

| Termo | Explicação simples |
|---|---|
| Evento | fato recebido de uma origem, como negócio ou mudança de ordem |
| Snapshot | fotografia de um estado em determinado instante |
| Manifesto | recibo da carga com contagens, totais, versão e hash |
| Feature | medida calculada dentro de janela e contexto |
| Finding | achado técnico produzido por um detector |
| Alert | findings relacionados que merecem triagem |
| Case | unidade formal de investigação e decisão |
| Reason code | código estruturado que explica por que algo ocorreu |
| Coorte | grupo comparável usado como baseline |
| Materialidade | tamanho econômico/exposição do padrão |
| Urgência | quão rápido o comportamento precisa ser tratado |
| `INCONCLUSIVE` | faltam dados críticos; não significa risco baixo |
| Point-in-time | usa apenas informação disponível naquele momento |
| Replay | reexecuta um período com snapshot e versões congelados |
| Idempotência | repetir não duplica o efeito lógico |
| Lineage | caminho da origem até o número mostrado |
| Entity resolution | decide se registros representam a mesma entidade |
| Grafo temporal | relações que possuem vigência e fonte |
| HHI | medida de concentração entre categorias/contrapartes |
| IPV | verificação independente de preço/valor |
| Turnover | volume negociado em relação ao patrimônio/base de capital |
| Audit ledger | sequência de eventos de auditoria |
| Hash chain | cada registro inclui o hash anterior, tornando adulteração detectável |
| Shadow mode | roda sem influenciar a decisão operacional |
| DLQ | fila de mensagens que falharam |
| RAG | recuperação de conteúdo aprovado para fundamentar IA |
| WORM | armazenamento que impede reescrita/exclusão conforme retenção |
