# Security policy

Não abra issues públicas com dados de clientes, credenciais, detalhes de vulnerabilidade explorável ou evidências de casos. Use o canal privado definido pelo owner do repositório.

Nunca inclua:

- dados reais não anonimizados;
- tokens, access keys ou URLs assinadas;
- dumps de produção;
- prompts/respostas contendo PII;
- detalhes de investigações.

Este repositório contém somente dados sintéticos. Antes de usar dados reais, aplique classificação, autorização, minimização, tokenização, retenção e segregação aprovadas.
